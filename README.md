# JM Enterprise Website (Local Clone)

A 100% local mirror of [jmenterprise.in](https://www.jmenterprise.in/) — works fully offline.

## Run locally

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080)

## Pages

- Home
- Products (Single Phase UPS, Three Phase UPS)
- 15 Product Detail pages
- Company Profile
- Contact Us
- Sitemap
